# BLF Service – Website (Netlify-Version)

Fertige Einzelseite für Netlify: Ordnerinhalt auf app.netlify.com/drop ziehen.

- `index.html` – die komplette Seite
- `img/` – Einsatzfotos von BLF (GAL-01 … GAL-34)
- `ext/` – Symbolbilder von Pexels (Pexels-Lizenz)
- `robots.txt` – Seite ist noch nicht für Suchmaschinen freigegeben

Vor dem Livegang: Netlify Forms aktivieren, Impressum/Datenschutz übernehmen, `noindex` und `robots.txt` entfernen.
