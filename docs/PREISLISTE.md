# Preisliste für die neue Website – was wir brauchen

Die Preise im Preisrechner kommen ausschließlich aus Ihrer offiziellen Preisliste. Wir tragen keine Preise selbst ein und schätzen keine fehlenden Preise.

## Am besten: Excel- oder Google-Sheets-Datei

Bitte schicken Sie die Datei, mit der Sie Ihre Preise heute pflegen (`.xlsx`, `.ods`, Google Sheets-Link oder `.csv`). Je Zeile **eine Reparatur für ein Modell**:

| Hersteller | Modell | Gerätetyp | Reparatur | Bezeichnung | Preis | Ab | Hinweis |
|---|---|---|---|---|---|---|---|
| Apple | iPhone 13 | Smartphone | Display | Original | 000,00 | | |
| Apple | iPhone 13 | Smartphone | Display | Kompatibel | 000,00 | | |
| Apple | iPhone 13 | Smartphone | Akku | | 000,00 | | |
| Samsung | Galaxy S24 | Smartphone | Wasserschaden | | auf Anfrage | | Preis nach Diagnose |

*(Die Zahlen oben sind Platzhalter, keine Preise.)*

- **Reparatur:** einer der Begriffe Display, Akku, Wasserschaden, Platine. Weitere Arten (z. B. Ladebuchse, Kamera, Rückglas) bitte nennen – wir legen sie an.
- **Bezeichnung:** optional, wenn es mehrere Varianten gibt (Original / Kompatibel).
- **Preis:** Endpreis in Euro, oder „auf Anfrage".
- **Ab:** „ja", wenn es ein Ab-Preis ist.
- **Hinweis:** optional, wird unter dem Preis angezeigt.
- Bitte angeben: Sind die Preise **inklusive MwSt.**? Gilt die Fehleranalyse von 25 € zusätzlich oder ist sie enthalten?

## Wenn es nur eine PDF oder ein Foto gibt

Dann bitte die PDF schicken. Wir übertragen sie in die Tabelle oben und schicken Ihnen die Tabelle **zur Freigabe**, bevor etwas veröffentlicht wird.

## Wenn die Preise heute im Preisrechner Ihrer alten Website stecken

Bitte teilen Sie uns mit, mit welchem System die alte Website gebaut ist und wer den Zugang hat (z. B. Website-Baukasten, Agentur). Dann exportieren wir die Daten von dort.

## Was danach passiert
1. Import der Datei mit Prüfung: unlesbare Preise, doppelte Zeilen und unbekannte Reparaturarten werden gemeldet, nichts wird geraten.
2. Stichprobe: 10 zufällige Zeilen werden gegen Ihre Vorlage verglichen.
3. Sie geben frei. Erst dann wird die Preisliste als „Geprüft" markiert und kann veröffentlicht werden.
4. Danach pflegen Sie die Preise selbst im Verwaltungsbereich der Website.
