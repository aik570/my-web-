# Photographs

Drop the files here with these exact names. Each slot on the page fills
itself as soon as the file exists; until then it shows the filename and the
size it wants.

| File | Size | Shot |
|---|---|---|
| `hero.jpg` | 2400 × 1400 | Dubai skyline or a tower facade at dusk |
| `living.jpg` | 1600 × 1200 | Living room with a view through full-height glass |
| `pool.jpg` | 1600 × 1200 | Waterfront villa, lap pool, sea |
| `terrace.jpg` | 1600 × 1200 | Wide terrace in evening light |
| `stair.jpg` | 1200 × 1600 | Vertical: staircase or hall in a mansion |
| `detail.jpg` | 1200 × 1200 | Square: close detail of stone, oak, brass |

Keep each file under about 400 KB or the page gets slow. Unsplash and
Pexels both allow this use; save the source link for your own records.
