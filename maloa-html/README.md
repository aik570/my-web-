# Ma'loa: редизайн на HTML + GSAP

Стек: чистый HTML, CSS и JS плюс GSAP 3 + ScrollTrigger с cdnjs. Без сборки
и без фреймворков, чтобы перенести в тему WordPress почти без изменений.
Прошлые демо лежат в `../maloa/`, бриф — в `../maloa/brief.md`.

## Hero: как работает

- **Заголовок** влетает по словам: `y 120 → 0`, `rotateX -90 → 0`, `opacity 0 → 1`, `power3.out`, stagger 0.08, 0.9 с.
- **Видео** (поворот боула, Kling 3.0 через Higgsfield):
  - перекодировано в 960 px, ключевой кадр каждые 4 кадра, 2.5 МБ;
  - кадр привязан к прогрессу скролла Hero (`scrub: true`);
  - грузится только на экранах ≥ 900 px, без reduced-motion и без data-saver;
  - на телефоне показывается постер (первый кадр видео, 45 КБ) с параллаксом.
- **Параллакс:** H1 `yPercent -18, opacity .4`, медиа `scale 1.05`.
- **Магнитные кнопки:** `gsap.quickTo` на x/y, 0.4 с, 30 % расстояния; на тач-экранах выключены.
- **Слайды** старого слайдера стали текстовыми кнопками-новостями: их можно перевести, и их видит поисковик.
- **Без прелоадера.**
- **Reduced motion:** ничего не скрыто и не анимируется, видео не грузится.

## Внешние медиа

Видео и постеры лежат на CDN Higgsfield, адреса собраны в `js/core.js`
(`MALOA.media`). Для продакшена их нужно перенести в медиатеку WordPress.
Если поставить `heroVideo: null`, Hero останется на постере.

## Перенос в WordPress

- CSS и JS подключаются через `wp_enqueue_style` / `wp_enqueue_script` в теме.
- Разметка секций переносится в шаблон главной или в блоки HTML.
- Если в теме уже есть шрифты `brandonweb-*` (плагин Use Any Font), они подхватятся сами: в `tokens.css` они стоят первыми.
