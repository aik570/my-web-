# Konzept Haus Collective — redesign concept

A redesign concept for kh-collective.com. It uses the studio's own copy, photos, films,
section colours and logo, all taken from the live site on 6 Nov 2026.

Open `index.html`. It works from disk with no internet and makes no external requests,
and it works on any static host.

## What is new compared with the current site

- **3D mark:** the KH logo, taken from the site's own SVG, is extruded into a glossy 3D
  object (three.js). It follows the mouse, turns away as you scroll, and changes colour
  with each section.
- **3D ring gallery:** 18 project images on a rotating ring, built with CSS 3D. It is pinned
  while you scroll, can be dragged with inertia or turned with the arrow keys, and opens
  the full project set on click.
- **Section colours as a system:** the site's seven colours (violet, rose, green, blue,
  orange, pink, black) now crossfade as you scroll and drive the 3D mark, nav, buttons
  and text.
- **Projects:** Gute Räume Hamburg, BU Düsseldorf and Le Coeur Düsseldorf, each with a
  draggable image strip, a lightbox, and the full text in a collapsible block.
- **Services:** the 12 services as a large list. A photo follows the cursor on hover.
- **Films:** the site's 6 films, compressed. They load and play only while on screen.
- **Contact:** WhatsApp, email and both phone numbers as large tap targets.
- **Manifest:** a dark final section, with each numbered line linking to its section.

## Structure

```
index.html          the page
css/fonts.css       Archivo, inlined (OFL), generated by build.mjs
css/style.css       styles
js/main.js          interactions
vendor/             gsap, ScrollTrigger, lenis, kh3d.js (three.js bundle), all local
media/img/          62 photos from the site, WebP, max 1600 px (~5 MB)
media/video/        6 films, H.264 without sound, plus poster frames (~13 MB)
src/kh3d.js         source of the 3D mark
build.mjs           rebuilds vendor/ and css/fonts.css
_headers, .htaccess security headers for Netlify / Cloudflare Pages / Apache
robots.txt          keeps the concept out of search engines
```

## Security

- **No third-party requests:** no CDN, no Google Fonts, no tracking, no cookies, no forms. Every script is a local file.
- **Content-Security-Policy:**
  - In a `<meta>` tag: `default-src 'none'`, scripts only from the site itself, no inline scripts, no `eval`, no frames, no forms, no network calls.
  - On hosting, `_headers` and `.htaccess` send the same policy as real headers. They also add `frame-ancestors 'none'` and `X-Frame-Options: DENY` (no clickjacking), `nosniff`, a strict referrer policy, a locked-down Permissions-Policy and `noindex`.
- **Safe DOM handling:**
  - The scripts never use `innerHTML`, `eval` or `document.write`.
  - Image and video paths are checked against fixed patterns before use.
  - Every external link has `rel="noopener noreferrer"`.
- **Search engines:** the concept is marked `noindex` (meta tag, header and robots.txt), so a hosted preview of the client's brand won't show up in search.
- **Hosting:** `.htaccess` turns off directory listing and blocks `build.mjs` and `README.md`.

## Rebuilding vendor files

```
npm i three@0.170.0 gsap@3.12.5 lenis@1.1.13 @fontsource-variable/archivo esbuild@0.24.0
node build.mjs ./node_modules
```
