# Ma'loa: редизайн, демо v2 (реальные фото)

Бриф проекта: [`brief.md`](brief.md). Прошлая версия с 3D-иллюстрациями: [`demo-v1-illustrations.html`](demo-v1-illustrations.html).

Структура, цвета и все анимации блоков из v1 сохранены. three.js больше не используется: вместо нарисованного боула стоят фото клиента.

| Блок | Что теперь |
|---|---|
| Hero | Настоящий боул сверху, медленно крутится. От скролла ускоряется, его можно раскрутить пальцем или мышью. Вокруг три мисочки с ингредиентами с параллаксом |
| Welcome / Favorites-интро | Блоки внахлёст, в карточках фото |
| Favorites | Слева закреплено фото боула, при скролле оно меняется вместе с названием и ккал |
| Poké your style | Боул при скролле разлетается на слои Base → Protein → Toppings → Flavor → Crunch, каждый слой вырезан из реальных фото |
| Gutschein / Franchise / Newsletter | Вторая «колода» внахлёст, с фото |

Анимируются только `transform` и `opacity`: затемнение карточек в колоде сделано слоем с opacity, а не `filter`. При `prefers-reduced-motion` страница показывается в покое, «разобранный вид» сразу раскрыт.

## Фото

Оригиналы лежат в `src/`, для сайта нарезаны WebP в `img/`.

| Файл в src | Что это | Где на сайте |
|---|---|---|
| spicy-salmon-tobiko.jpg | Лосось, тобико, авокадо | Hero; Favorites: Big Island (символическое фото) |
| peanutlover.jpg | Курица, арахисовый соус | Favorites: Peanutlover, Vul'cano (символическое); мисочки соуса и арахиса |
| spicy-tropical.jpg | Тофу, манго, кокос | Favorites: Spicy Tropical, Sesam Me (символическое); Gutschein |
| lanai.jpg | Тунец, свёкла, авокадо | Favorites: Lanai; финальный боул в Poké your style; Newsletter |
| salmon-cashew.jpg | Лосось, кешью, водоросли | Favorites: Kauai, Molokai (символическое); Franchise |
| shrimp-wasabi.jpg | Креветки, васаби-орешки | Welcome; мисочка эдамаме |
| beet-falafel.jpg | Фалафель из свёклы, гуакамоле | Карточка Favorites |
| logo-*.jpg, monogram.jpg | Логотип, монограмма | Прозрачные PNG/WebP и фавиконы в `img/` |

Где подписано «Symbolfoto», фото подобрано по основному белку, отдельного снимка этого боула нет. Когда клиент пришлёт снимки, достаточно положить вырез в `img/bowl-<name>-560.webp` и поправить `data-img` у пункта списка.
