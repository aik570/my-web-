## 4. Стек и правила

- Чистый HTML + CSS + JS. **GSAP 3.15** (ScrollTrigger, DrawSVGPlugin) с jsDelivr. Без React/Next — позже перенос в WordPress.
- Анимировать только `transform` / `opacity` (+ `clip-path` как исключение).
- На каждое движение — вариант для `prefers-reduced-motion`. Фокус с клавиатуры. Кнопка паузы у зацикленного видео (WCAG 2.2.2). «Bestellen» всегда на виду.
- Нет горизонтального скролла ни на одной ширине.
- **Работа по шагам:** один блок → показать → подтверждение → следующий. Коммит после каждого шага.
- **Higgsfield:** ничего не генерировать и не тратить кредиты без явного «да» Коли. Сначала назвать модель и цену. Баланс после этой сессии около 536 кредитов из плана Pro.

### 7.2 HERO → LEAVES → раскрытие боула (УТВЕРЖДЁН)
- **Файлы:** `index.html` → `<div class="scene" id="scene">`. Внутри: `#hero`, `.scene__dim`, `.welcome#welcome` (боул), `.leaves` (8 `<img class="leaf">`). Стили `css/scene.css`, скрипт `js/scene.js`.
- **Без скрипта** (нет GSAP или reduced motion): Hero, потом экран с боулом, листья скрыты. Скрипт добавляет класс `.scene--cinematic`: сцена становится одним экраном (`100svh`, overflow hidden), затемнение, боул и листья — абсолютные слои.
- **Закрепление:** ScrollTrigger `pin`, `start: 'top top'`.
  - Компьютер: `end: '+=220%'`, `scrub: 0.9`.
  - Телефон (`max-aspect-ratio: 4/5`): `end: '+=150%'`, `scrub: 0.5`.
  - Везде: `ScrollTrigger.config({ ignoreMobileResize: true })`, варианты через `gsap.matchMedia()`.
- **Таймлайн** (доли общего прогресса 0…1):
  - 0–0,34 — листья входят из-за краёв (`power2.out`). Путь = направление `data-dir` × `T.enter` × глубина `data-depth`.
  - 0–0,18 — текст, скролл и пауза Hero уходят вверх (`autoAlpha 0, y -40`).
  - 0–0,56 — `.hero__media` уменьшается до 0,88 (телефон 0,94); `.scene__dim` → opacity 0,55.
  - 0,34–0,56 — листья чуть смыкаются, ближние растут (`scale 1 + 0.1*depth`).
  - 0,56–0,98 — листья расходятся занавесом и уходят за край (`power2.in`).
  - 0,52–0,96 — боул раскрывается кругом `clip-path: circle(0% → 100% at 50% 50%)`; `.welcome__inner` из `scale 1.1` в 1; `.welcome__visual` доворачивается с `rotation -12` в 0.
  - Параметры пути `T`: компьютер `{enter:58, close:15, exit:96, turn:9}`, телефон `{enter:44, close:7, exit:78, turn:0}` (vw/vh на единицу глубины; `turn` — 3D-поворот листа по Y).
- **Видео:** когда прогресс больше 0,97, видео Hero ставится на паузу (`syncVideo`); при скролле назад продолжает играть, если посетитель сам не ставил паузу.

### 7.9 ПЛАВНОСТЬ АНИМАЦИЙ И СКРОЛЛА (03.10, ТЗ Коли; дизайн не менялся, ждёт просмотра)
- **Причина рывков:** в Favorites и Poké стоял ScrollTrigger `snap`. После остановки пользователя snap сам докручивал страницу к ближайшей метке: при входе в секцию тянул назад (Poké: до −240 px), а в Favorites по инерции проскакивал целую боул вперёд (+750 px). Отсюда «перескоки» между состояниями 2→3 и 4→5. Плюс `scrub` 0.6–0.9 с — анимация догоняла скролл с заметной задержкой.
- **Новая архитектура:** snap убран везде. Состояние считается только из позиции скролла: `MALOA.rest(x, n, h)` (`js/core.js`) даёт «паузу» вокруг каждого состояния и движение между ними. Ощущается как фиксация, но страницу никто не двигает; назад — тот же путь. `scrub` 0.35, `anticipatePin: 1`, `overflow-anchor: none` (base.css), обновление замеров после загрузки шрифта — один раз в core.js.
- **Favorites:** один pin + один driver; колесо начинает поворачиваться (первая боул въезжает в кольцо), пока сцена ещё поднимается снизу — секция «живая» сразу. Заголовок появляется, как только попадает в кадр. Индекс 01–05 скроллит к середине паузы нужной боул.
- **Poké:** таймлайн на паузе, время ставится из скролла через `MALOA.rest`. Ингредиенты «кладутся»: чуть сверху и чуть крупнее → на место, `power3.out`, без `back.out`, без поворота мелочи, проявление до конца движения. Соус растекается под мягкой радиальной маской (не жёсткий круг). Убран «пульс» тарелки.
- **Hero:** под видео лежит постер (тот же первый кадр) фоном; видео плавно проявляется, когда реально играет с запасом буфера. На тач-устройствах у стеклянных кнопок и пилюль меню нет живого blur поверх видео (он пересчитывался на каждый кадр). Само видео — 24 fps (исходник Kling); сделать его плавнее можно только перекодированием с интерполяцией кадров — не делалось.
- **Раскрытие боула:** круг теперь с мягким растушёванным краем (radial mask), после раскрытия маска снимается. Под боулом — маленькая подпись Maui · Tuna Bowl, ингредиенты, 498 kcal (те же данные, что в Favorites).
- **Переходы:** вместо анимации цвета фона (About) — длинные статичные полосы цветов CI (night → deep teal → mid teal → light gray → light) сверху About и обратно сверху Favorites, с плавными стопами; их просто проскролливают. Маска фото Welcome начинается с реальных радиусов (не 999px), ход длиннее и мягче.
